# Глоссарий

Термины в том значении, в котором они используются в этом демо и в коде.

| Термин                               | Определение                                                                                                                              |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Арендатор (tenant)**               | Изолированный клиент системы. В демо один — «ВЕКТОР» (`TENANT_ID`). Изоляция держится составными внешними ключами в Postgres             |
| **База знаний (knowledge base, kb)** | Набор документов, по которым идёт поиск. Демо работает с одной базой (`KB_ID`); модель данных допускает несколько                        |
| **Документ**                         | Логическая единица базы: `external_id` (`about-vektor`), заголовок, аудитория, раздел, теги. Хранится в `documents`                      |
| **Версия документа**                 | Один текст документа с SHA-256. Повторная загрузка того же текста версии не создаёт. Хранится в `document_versions` вместе с `full_text` |
| **Фрагмент (chunk)**                 | Кусок текста версии, проиндексированный отдельно. Единица поиска и цитирования                                                           |
| **Аудитория (audience)**             | Кому виден документ: `public` — всем, `employee` — только сотрудникам. Фильтруется в запросе к Elasticsearch                             |
| **Principal**                        | Аутентифицированный пользователь: `user_id`, логин, имя, роль, `tenant_id`, `kb_id` и набор `audiences`. Собирается из подписанного JWT  |
| **Роль**                             | `user` (клиент) или `employee` (сотрудник). Клиент видит `(public,)`, сотрудник — `(public, employee)`. Берётся только из токена         |
| **Guard / классификатор**            | Лексическая проверка запроса до поиска: инъекция в промпт, платёжные данные. Может только запретить, прав не выдаёт                      |
| **Retrieval (поиск)**                | Гибридный поиск фрагментов: BM25 + kNN, объединённые RRF, после фильтра прав                                                             |
| **RRF (Reciprocal Rank Fusion)**     | Способ объединить два ранжирования по местам: `sum 1/(k+rank)`, `k=60`. Складывать BM25 и косинус напрямую нельзя — шкалы разные         |
| **e5**                               | Модель эмбеддингов `intfloat/multilingual-e5-small` (ONNX, 384 измерения). Префиксы `query: ` и `passage: `, mean pooling, L2            |
| **Цитата (citation)**                | Ссылка в ответе на использованный фрагмент: номер, документ, версия, цитата, локатор, `download_url`                                     |
| **Локатор (locator)**                | Где фрагмент находится в документе: `section_path`, `page_start`/`page_end`, `block_ids` (в демо пуст)                                   |
| **`no_evidence`**                    | Статус ответа «подтверждающих материалов нет». Клиенту в этом случае модель не вызывается                                                |
| **Cookie-сессия**                    | JWT в `httpOnly` cookie `vektor_session`. Браузер присылает её сам, JS токен не читает                                                   |
| **Сид (seed)**                       | Засев демо-корпуса из `infra/scripts/data/corpus.json`. Идемпотентен                                                                     |

См. также [reference/api.md](reference/api.md) — контракт платформы.
