## Что сделано

| Область | Результат |
| --- | --- |
| Фильтр прав в индексе | §6-фильтр (`space_id`/`acl`, minimum_should_match) внутри запроса ES; пустая область → `match_none`; kNN-фильтр вложен в `knn.filter` |
| Права в конвейере | Конверт → ParsedDocument → Chunk.Rights; без прав документ невидим |
| Утечка `acl_override` | Закрыта: переопределение администратора **снимает** контейнер (иначе OR-фильтр протекает) |
| Lake | `raw_events` (партиционированная), `raw_event_ids` (идемпотентность), DLQ, AGDLP-таблицы, `doc_edges` |
| Продюсеры lake | Индексация публикует `index`-снимок; удаление публикует надгробие `delete` (6-я стадия) |
| Удаление | Стадия `delete` в воркере: надгробие в lake → `delete_by_query` по `(tenant_id, document_id)` |
| Пересборка | `internal/jobs/rebuild` + CLI `cmd/rebuild`: fold lake → документы → индекс; надгробия уважаются |
| Живой путь поиска | `search/service` переведён на `SecuredSearchIndex` + `ResolveScope`; старый путь недостижим на уровне компиляции |
| Ворота §9 | Матрица прав 7×11=77 клеток, отрицательный контроль, удаление, свежесть, пересборка |
| Eval | 141 вопрос, гейт «гибрид ≥ BM25», CLI `kbeval` |

## Проверено на живых сервисах

`go build`, `go vet`, `gofmt` — чисто. `go test ./...` — **440 PASS, 0 FAIL**
против настоящих Postgres 16 и Elasticsearch 8.17.3.

Восстановление индекса на живом стенде: `документов: 1, чанков: 3`; надгробие
убирает документ из пересборки; две пересборки дают идентичный индекс.

## Исправленные дефекты CI

1. `ci.yml` запускал `./internal/infrastructure/...` — каталога нет после
   перестройки, интеграционные тесты не выполнялись вообще. Перенаправлено на
   `./internal/store/... ./internal/arch/...`.
2. Ворота удаления на живом индексе вынесены в отдельный шаг с
   `KB_GO_GATES_CLUSTER=1` (общий прогон конфликтует с cleanup индексов).
3. `migtest_test.go` читал `TEST_DATABASE_URL`, CI задаёт
   `KB_GO_TEST_DATABASE_URL` — миграции молча пропускались. Ожидание версии
   обновлено 1 → 3.

## Открыто

- Lake-запись не атомарна с активацией версии (`ports.EventBus` — замороженный шов).
- Свежесть коннекторов существует только в SQL, без Go-метрики.
- §9 требует 100 **реальных** вопросов; набор из 141 — синтетический, из фикстур.
- `GetAllowedActiveVersions` в проверке после выдачи читает шире, чем 20–50 кандидатов.
- ClickHouse, Kafka, LLM-ответы, комментарии, граф, desktop, MCP — фазы 2–4.
